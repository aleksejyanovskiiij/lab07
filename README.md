# Лабораторная работа №7. Эмбеддинги, чанки и метрики расстояний

## Выполненные работы

В работе проанализированы готовые чанки (число чанков на документ, длины в словах), три стратегии разбиения текста на чанки (по символам без перекрытия, с перекрытием 50 и по предложениям) и их сравнение с готовыми чанками. Посчитаны четыре метрики расстояний (cosine, euclidean, cityblock, dot product), исследовано влияние L2-нормализации и z-score (StandardScaler) на порядок соседей. Выполнен поиск ближайших чанков по косинусу и евклиду, а также PCA-визуализация эмбеддингов из задания 7.2. Все выводы подкреплены таблицами и числами.

## Процесс запуска

1. `pip install -r requirements.txt`
2. Откройте ноутбук `lab7.ipynb`
3. Выполните все ячейки сверху вниз.
